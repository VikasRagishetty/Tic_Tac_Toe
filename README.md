# Tic Tac Toe

A simple Tic Tac Toe game built using React, JavaScript, HTML, and Tailwind CSS.

## Features

- Two-player Tic Tac Toe
- Score tracking
- Move history
- Sound effects
- Game settings
- Responsive design

## Technologies Used

- React
- JavaScript
- HTML
- Tailwind CSS
- Vite

## How to Run

1. Clone the repository
2. Open the project folder
3. Install dependencies:

```bash
npm install
